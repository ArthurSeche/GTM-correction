Tracking des éléments du site

Avant tout : activer les variables intégrées

Variables → Variables intégrées → Configurer, puis cocher : Click Element, Click Classes, Click ID, Click URL, Click Text, Page Path, Form ID.

2.1 — Le bouton « Découvrir le maillot » 0,75 pt

Technique : clic ciblé par l'ID de l'élément (hero-cta, visible avec l'inspecteur : clic droit → Inspecter).

  1. Déclencheur Clic – Liens uniquement, « Certains clics sur des liens » : Click ID est égal à hero-cta. Nom : Clic - CTA accueil.
  2. Balise Événement GA4, ID de mesure {{CONST - ID mesure GA4}}, nom d'événement clic_cta_accueil, sur ce déclencheur.

Test : clic sur « Découvrir le maillot » → balise déclenchée ; clic sur « Voir la boutique » → non déclenchée.

2.2 — Téléphone et e-mail 1 pt

Technique : la variable Click URL. Un lien téléphone commence par tel:, un lien e-mail par mailto:.

Solution A — deux déclencheurs, deux balises (acceptée)

  • Déclencheur Clic - telephone : Clic – Liens uniquement, Click URL commence par tel:. Balise clic_contact avec le paramètre moyen = telephone.
  • Déclencheur Clic - email : Click URL commence par mailto:. Balise clic_contact avec moyen = email.

Solution B — une seule balise (la plus propre)

  1. Variable Table d'expressions régulières nommée RegEx - moyen de contact, variable d'entrée {{Click URL}} :
    ModèleRésultat
    ^tel:telephone
    ^mailto:email
  2. Déclencheur : Clic – Liens uniquement, Click URL correspond à l'expression régulière ^(tel|mailto):.
  3. Balise clic_contact avec moyen = {{RegEx - moyen de contact}}.

Test : sur la page Contact, un clic sur le numéro donne moyen: telephone, un clic sur l'adresse donne moyen: email. L'ordinateur peut proposer d'ouvrir une application : il suffit d'annuler.

2.3 — Les réseaux sociaux 1 pt

Technique : une classe commune pour le déclencheur, un attribut pour la valeur. Dans le code, chaque lien a la forme <a class="social-link" data-network="instagram" …>.

  1. Variable Variable d'événement automatique, type Attribut de l'élément, nom de l'attribut data-network. Nom : Clic - reseau.
  2. Déclencheur Clic – Liens uniquement : Click Classes contient social-link.
  3. Balise clic_reseau_social avec le paramètre reseau = {{Clic - reseau}}.

Variante acceptée : reseau = {{Click Text}}. Elle donne « Instagram » avec une majuscule, et casse si le texte du lien change : c'est moins robuste.

À savoir : ces liens mènent vers d'autres sites. Avec la mesure améliorée, GA4 envoie aussi automatiquement un événement click (paramètre outbound: true). Ce n'est pas un doublon : c'est un événement générique pour tous les liens sortants, alors que clic_reseau_social répond à une question métier précise.

2.4 — Le catalogue PDF 1 pt

  1. Déclencheur Clic – Liens uniquement : Click URL se termine par .pdf (ou contient catalogue). Il couvre les deux liens : le bouton de la boutique et le lien du pied de page.
  2. Balise telechargement_catalogue sur ce déclencheur.
Réponse attendue à la question : GA4 envoie déjà un événement file_download, grâce à la mesure améliorée (option « Téléchargements de fichiers », activée par défaut sur le flux). Il détecte tout seul les clics vers des fichiers .pdf, .xlsx, .zip… On a donc deux événements pour un même clic. Deux réponses sont acceptées si elles sont justifiées :
  • garder les deux : file_download compte tous les fichiers, telechargement_catalogue isole le catalogue ;
  • ne garder que file_download et filtrer sur son paramètre file_name : on supprime alors sa propre balise, ou on désactive l'option dans le flux.
La mauvaise réponse est de ne pas avoir remarqué le doublon.

2.5 — Le formulaire de contact 1,25 pt

Le formulaire envoie vers contact-merci.html?sujet=taille. Seul le sujet apparaît dans l'adresse : le nom, l'e-mail et le message n'y sont volontairement pas, pour ne jamais faire remonter de données personnelles à GA4.

Méthode recommandée — la page de remerciement

  1. Variable URL, type de composant Requête, clé de requête sujet. Nom : URL - sujet.
  2. Déclencheur Page vue, « Certaines pages vues » : Page Path contient contact-merci.
  3. Balise generate_lead avec le paramètre sujet = {{URL - sujet}}.

Pourquoi c'est la meilleure : on n'arrive sur cette page qu'après un envoi réussi (champs remplis et valides). Limite : un visiteur qui recharge la page compte deux fois.

Méthode acceptée — l'envoi du formulaire

  1. Déclencheur Envoi de formulaire, cocher Vérifier la validation, « Certains formulaires » : Form ID est égal à contact-form.
  2. Variable JavaScript personnalisé pour lire le sujet choisi :
function () {
  return document.getElementById("contact-sujet").value;
}
  1. Balise generate_lead avec sujet = cette variable.

Test : envoyer le formulaire avec le sujet « Une question de taille » → generate_lead avec sujet: taille. Cliquer sur Envoyer avec un champ vide → rien ne part.

Le piège évité : ne jamais envoyer le contenu des champs nom, e-mail ou message à GA4. C'est interdit par les conditions d'utilisation de Google Analytics, et contraire au RGPD.
