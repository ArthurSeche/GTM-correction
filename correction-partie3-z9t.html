E-commerce

3.1 — La configuration GTM 1 pt

  1. Déclencheur Événement personnalisé, nom CE - E-commerce GA4, nom de l'événement :
^(view_item|add_to_cart|remove_from_cart|begin_checkout|add_shipping_info|add_payment_info|purchase)$
  1. Cocher Utiliser la correspondance d'expression régulière, « Tous les événements personnalisés ».
  2. Balise Événement GA4 GA4 - Événement e-commerce : ID {{CONST - ID mesure GA4}}, nom d'événement {{Event}}.
  3. Plus de paramètres → cocher Envoyer les données d'e-commerce, source Couche de données. Déclenchement : CE - E-commerce GA4.

^ et $ imposent une correspondance exacte : purchase_test ne sera pas capté. Une regex plus longue (avec view_item_list, add_to_wishlist…) est aussi juste.

3.2 à 3.5 — Le code complet de mes-tags.js

À coller après les deux premières lignes du fichier (window.dataLayer = … et window.shopHooks = …). Le fichier mes-tags-correction.js contient le même code.

/* Le dictionnaire : vocabulaire de la boutique → vocabulaire GA4 */
function versItem(x) {
  return {
    item_id: x.sku,
    item_name: x.name,
    item_brand: x.brand,
    item_category: x.category,
    item_variant: x.size,
    price: x.price,
    quantity: x.quantity || 1
  };
}

/* 3.2 — Vue d'un produit */
shopHooks.viewItem = function (data) {
  dataLayer.push({ ecommerce: null });
  dataLayer.push({
    event: "view_item",
    ecommerce: {
      currency: "EUR",
      value: data.product.price,
      items: [versItem(data.product)]
    }
  });
};

/* 3.3 — Ajout au panier */
shopHooks.addToCart = function (data) {
  var item = versItem(data.product);
  item.item_variant = data.size;
  item.price = data.unitPrice;
  item.quantity = data.quantity;
  dataLayer.push({ ecommerce: null });
  dataLayer.push({
    event: "add_to_cart",
    ecommerce: { currency: "EUR", value: data.value, items: [item] }
  });
};

/* 3.4 — Tunnel de commande */
shopHooks.beginCheckout = function (data) {
  dataLayer.push({ ecommerce: null });
  dataLayer.push({
    event: "begin_checkout",
    ecommerce: {
      currency: "EUR",
      value: data.totals.subtotal - data.totals.discount,
      coupon: data.totals.coupon || undefined,
      items: data.lines.map(versItem)
    }
  });
};

shopHooks.addShippingInfo = function (data) {
  dataLayer.push({ ecommerce: null });
  dataLayer.push({
    event: "add_shipping_info",
    ecommerce: {
      currency: "EUR",
      value: data.totals.subtotal - data.totals.discount,
      coupon: data.totals.coupon || undefined,
      shipping_tier: data.shippingTier,
      items: data.lines.map(versItem)
    }
  });
};

shopHooks.addPaymentInfo = function (data) {
  dataLayer.push({ ecommerce: null });
  dataLayer.push({
    event: "add_payment_info",
    ecommerce: {
      currency: "EUR",
      value: data.totals.subtotal - data.totals.discount,
      coupon: data.totals.coupon || undefined,
      payment_type: data.paymentType,
      items: data.lines.map(versItem)
    }
  });
};

/* 3.5 — Achat */
shopHooks.purchase = function (data) {
  if (!data.firstView) return; // page rechargée : on n'envoie pas l'achat une 2e fois
  var o = data.order;
  dataLayer.push({ ecommerce: null });
  dataLayer.push({
    event: "purchase",
    ecommerce: {
      transaction_id: o.transaction_id,
      currency: o.currency,
      value: Math.round((o.total - o.shipping) * 100) / 100,
      tax: o.tax,
      shipping: o.shipping,
      coupon: o.coupon || undefined,
      items: o.lines.map(versItem)
    }
  });
};

/* Bonus — Retrait du panier */
shopHooks.removeFromCart = function (data) {
  var item = versItem(data.line);
  item.quantity = data.quantity;
  dataLayer.push({ ecommerce: null });
  dataLayer.push({
    event: "remove_from_cart",
    ecommerce: { currency: "EUR", value: data.value, items: [item] }
  });
};

Les points qui font gagner ou perdre des points

  • 3.2 : les noms GA4 (item_id, pas id ; item_name, pas name). Une fonction de traduction comme versItem n'est pas obligatoire, mais elle est valorisée.
  • 3.3 : le crochet addToCart n'est appelé que si l'ajout réussit : un clic sans taille n'envoie rien. Le prix vient de data.unitPrice (105 € avec flocage), pas de data.product.price.
  • 3.4 : shipping_tier et payment_type sont au même niveau que value, dans l'objet ecommerce.
  • 3.5 : le test sur data.firstView empêche le doublon au rechargement. Le choix d'inclure ou non les frais de port dans value est libre, s'il est cohérent.
  • Partout : dataLayer.push({ ecommerce: null }) avant chaque push e-commerce.
