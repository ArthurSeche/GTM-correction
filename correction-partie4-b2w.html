Variables et exploitation dans GA4

4.1 — La commande premium 1 pt

  1. Variable Variable de couche de données DLV - montant commande, nom ecommerce.value, version 2.
  2. Déclencheur Événement personnalisé CE - purchase premium : nom d'événement purchase, « Certains événements personnalisés », DLV - montant commande supérieur ou égal à 100.
  3. Balise Événement GA4 commande_premium sur ce déclencheur.

Test : 1 maillot (90 €) → pas de commande_premium ; 2 maillots (180 €) → commande_premium part juste après purchase. Dans Tag Assistant, l'onglet Variables montre la valeur lue.

4.2 — Les dimensions personnalisées 1 pt

GA4 → Administration → Définitions personnalisées → Créer une dimension personnalisée, trois fois :

Nom de la dimensionChamp d'applicationParamètre d'événement
Moyen de contactÉvénementmoyen
Réseau socialÉvénementreseau
Sujet du contactÉvénementsujet

Le nom est libre ; le paramètre doit être écrit exactement comme dans les balises GTM. Une dimension ne se remplit qu'à partir de sa création.

4.3 — Les événements clés 0,5 pt

  1. GA4 → Administration → Événements clés → Nouvel événement clé.
  2. Saisir generate_lead, enregistrer. Recommencer avec commande_premium.

On peut aussi les marquer depuis la liste des événements (Administration → Événements), mais seulement une fois qu'ils ont été reçus. purchase est un événement clé par défaut.

4.4 — L'exploration de l'entonnoir 1 pt

  1. GA4 → Explorer → Exploration de l'entonnoir. Renommer l'exploration « Tunnel Kop Store ».
  2. Dans « Étapes », cliquer sur le crayon et créer 6 étapes, chacune avec la condition Nom de l'événement = … :
ÉtapeÉvénement
1. Vue produitview_item
2. Ajout au panieradd_to_cart
3. Début de commandebegin_checkout
4. Livraisonadd_shipping_info
5. Paiementadd_payment_info
6. Achatpurchase

Entonnoir ouvert ou fermé : les deux sont acceptés. Question de bilan : dans un entonnoir fermé, un visiteur qui arrive directement sur la page commande n'est pas compté. L'exploration sera vide tant que GA4 n'a pas traité les données (24 à 48 h).

4.5 — L'audience « Paniers abandonnés » 0,5 pt

  1. GA4 → Administration → Audiences → Nouvelle audience → Créer une audience personnalisée.
  2. Nom : « Paniers abandonnés ». Inclure les utilisateurs quand : événement add_to_cart.
  3. Cliquer sur Ajouter un groupe pour exclure : exclure les utilisateurs quand l'événement purchase se produit.
  4. Durée d'appartenance : par exemple 30 jours. Enregistrer.

Usage : relancer ces visiteurs avec une publicité ou un e-mail, si l'audience est partagée avec Google Ads.
