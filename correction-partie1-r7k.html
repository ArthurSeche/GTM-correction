Installation de GA4 et GTM

1.1 — La propriété et le flux GA4

  1. GA4 → Administration (roue dentée) → Créer → Propriété.
  2. Nom « Kop Store Examen – Nom », fuseau horaire France, devise Euro (EUR). Renseigner les informations sur l'entreprise et les objectifs, puis Créer.
  3. Plate-forme : Web. URL du site : votre-pseudo.github.io, nom du flux : « Site examen ». Laisser la mesure améliorée activée, puis Créer le flux.
  4. Copier l'ID de mesure affiché en haut à droite : G-XXXXXXXXXX. On le retrouve plus tard dans Administration → Collecte et modification des données → Flux de données.
Réponse attendue : la propriété est l'espace qui contient les données et les rapports d'un site (ou d'un ensemble site + application). Le flux est la source qui alimente cette propriété : un flux Web pour un site, un flux iOS ou Android pour une application. C'est le flux qui fournit l'ID de mesure.

1.2 — Installer GTM

Créer le conteneur

  1. tagmanager.google.com → choisir le compte → Créer un conteneur (ou créer un compte si besoin).
  2. Nom « Kop Store Examen – Nom », plate-forme cible Web → Créer.
  3. GTM affiche les deux codes d'installation. On les retrouve plus tard dans Administration → Installer Google Tag Manager.

Toutes les pages : gtm-install.js

  1. Dans le dépôt GitHub, ouvrir gtm-install.js → icône crayon.
  2. Ligne 8, coller l'ID du conteneur entre les guillemets :
var GTM_ID = "GTM-ABC1234";
  1. Commit changes, attendre la coche verte dans l'onglet Actions, recharger le site avec Ctrl + F5. Dans la console, l'avertissement « Aucun conteneur GTM » doit avoir disparu.

La page installation.html : à la main

Le code 1 se colle le plus haut possible dans le <head>, juste après <meta charset="utf-8"> :

<!-- Google Tag Manager -->
<script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],
j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src=
'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);
})(window,document,'script','dataLayer','GTM-XXXXXXX');</script>
<!-- End Google Tag Manager -->

Le code 2 se colle juste après la balise d'ouverture <body …> :

<!-- Google Tag Manager (noscript) -->
<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=GTM-XXXXXXX"
height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript>
<!-- End Google Tag Manager (noscript) -->
Pourquoi ces emplacements ? Le code du <head> doit se charger le plus tôt possible, pour ne rater aucune action du visiteur. Le code <noscript> ne sert qu'aux navigateurs sans JavaScript ; il doit être dans le <body>, car une <iframe> n'a pas le droit d'être dans le <head>.

Erreurs fréquentes : les deux codes collés au même endroit ; l'ID oublié dans l'un des deux codes ; un code collé à l'intérieur d'une autre balise <script>.

1.3 — Brancher GA4 dans GTM

La variable constante

  1. Variables → Variables définies par l'utilisateur → Nouvelle.
  2. Nom : CONST - ID mesure GA4. Type : Constante. Valeur : G-XXXXXXXXXX. Enregistrer.

La balise Google

  1. Balises → Nouvelle → type Balise Google.
  2. ID de la balise : {{CONST - ID mesure GA4}}.
  3. Déclenchement : Initialisation – Toutes les pages. Nom : GA4 - Balise Google. Enregistrer.

La vérification

  1. Prévisualiser → adresse de hello.html → la balise Google est dans « Balises déclenchées ».
  2. Dans la même session, aller sur installation.html : Tag Assistant reste connecté et la balise se déclenche aussi. Si ce n'est pas le cas, l'installation manuelle est fausse.
  3. GA4 → Rapports → Temps réel : au moins 1 utilisateur actif.
Pourquoi une constante ? Si l'ID change (nouvelle propriété, propriété de test), on le modifie à un seul endroit au lieu de rouvrir toutes les balises.

1.4 — Accès et publication

  • GTM : Administration → Gestion des utilisateurs (au niveau du conteneur) → « + » → adresse du formateur, autorisation Lecture.
  • GA4 : Administration → Gestion des accès à la propriété → « + » → adresse du formateur, rôle Lecteur.
  • Publication : bouton Envoyer → nom de la version « Partie 1 » → Publier.
